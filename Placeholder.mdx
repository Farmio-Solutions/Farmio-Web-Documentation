## Employees & Crews

### Add one employee

1. Select the **Crew** page <img src="/images/IMG_9638.jpg" alt="Crew icon mobile" noZoom style={{ width: "32px", height: "auto", display: "inline-block", verticalAlign: "middle", margin: 0 }} /> from the bottom menu.

![IMG 9637](/images/IMG_9637-1.jpg "IMG 9637")

2. Select the + button in the top right of the page.

![IMG 9626 1](/images/IMG_9626-1.png "IMG 9626 1")

3. Enter the employee's first name, last name, and employee ID.\*

_\*Optional: Add a custom pay rate for the employee._

4. Select **Create Member** to save your new employee.

![IMG 9627](/images/IMG_9627.PNG "IMG 9627")

---

### Update employee details

1. Select the **Crew** page <img src="/images/IMG_9638.jpg" alt="Crew icon mobile" noZoom style={{ width: "32px", height: "auto", display: "inline-block", verticalAlign: "middle", margin: 0 }} /> from the bottom menu.

![IMG 9637](/images/IMG_9637-1.jpg "IMG 9637")

2. Select the **Search** box above the employee list.
3. Enter the employee's first name, last name, or Employee ID.
4. Select the employee you want to update.

![IMG 9634](/images/IMG_9634.PNG "IMG 9634")

5. Select the edit button <img src="//images/IMG_9635-2.jpg" alt="Edit Button" noZoom style={{ width: "30px", height: "auto", display: "inline-block", verticalAlign: "middle", margin: 0 }} /> on the employee's profile.

![IMG 9635](/images/IMG_9635.jpg "IMG 9635")

6. Update the employee's first name, last name, employee ID, custom rate, member status, or profile picture.
7. Select **Update Profile** to save your changes.

![IMG 9631](/images/IMG_9631.PNG "IMG 9631")

---

### Export an employee badge

1. Select the **Crew** page <img src="/images/IMG_9638.jpg" alt="Crew icon mobile" noZoom style={{ width: "32px", height: "auto", display: "inline-block", verticalAlign: "middle", margin: 0 }} /> from the bottom menu.

![IMG 9637](/images/IMG_9637-1.jpg "IMG 9637")

2. Select the **Search** box above the employee list.
3. Enter the employee's first name, last name, or Employee ID.
4. Select the employee you want to update.

![IMG 9634](/images/IMG_9634.PNG "IMG 9634")

5. Select the **export** button <img src="/images/image-7.png" alt="Crew icon mobile" noZoom style={{ width: "32px", height: "auto", display: "inline-block", verticalAlign: "middle", margin: 0 }} /> in the top right of the page.

![IMG 9676](/images/IMG_9676.png "IMG 9676")

You can save, share, or print the employee badge.

![IMG_9663-2](images/IMG_9663-2.png "IMG_9663-2")
