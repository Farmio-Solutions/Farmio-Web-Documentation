## Employees & Crews

### Add one employee

1. Select the **Crew** page <img src="/images/IMG_9638.jpg" alt="Crew icon mobile" noZoom style={{ width: "32px", height: "auto", display: "inline-block", verticalAlign: "middle", margin: 0 }} /> from the bottom menu.

![IMG 9637](/images/IMG_9637-1.jpg "IMG 9637")

2. Select the + button in the top right of the page.

![IMG 9626 1](/images/IMG_9626-1.png "IMG 9626 1")

3. Enter the employee's first name, last name, and employee ID.\*

_\*Optional: Add a custom pay rate for the employee._

4. Select **Create Member** to save your new employee.

## Employee Time Tracking

### Clock employees in

1. Select the **Timecard** page <img src="/images/IMG_9865-4.PNG" alt="Crew icon mobile" noZoom style={{ width: "32px", height: "auto", display: "inline-block", verticalAlign: "middle", margin: 0 }} /> from the bottom menu.

![IMG 9865](/images/IMG_9865-2.PNG "IMG 9865")

2. Find and select the timecard you want to clock employees in for.

![IMG 9813](/images/IMG_9813.PNG "IMG 9813")

3. Under **Timecard tasks**, select **Scan now** in the **Clock In Members** section.

![IMG 9814](/images/IMG_9814.PNG "IMG 9814")

4. Select **Scan per group** or **Scan per individual**.

- **Scan per group**: assign members to a group for the current time card.
- **Scan per individual**: scan in employees without creating groups for the current time card.

![IMG 9815](/images/IMG_9815.PNG "IMG 9815")

5. Scan the QR codes on each employee's badge.

- The employee names will show up under **Selected Members** as they are successfully scanned.

6. Select **Clock In Members**. 

![IMG 9818](/images/IMG_9818.PNG "IMG 9818")

A **confirmation screen** appears, showing the number of employees successfully clocked in and the timecard number.

![IMG 9841](/images/IMG_9841.PNG "IMG 9841")

### Record employee breaks

1. Select the **Timecard** page <img src="/images/IMG_9638.jpg" alt="Crew icon mobile" noZoom style={{ width: "32px", height: "auto", display: "inline-block", verticalAlign: "middle", margin: 0 }} /> from the bottom menu.
2. Find and select the timecard you want to record a break for.
3. Select **Morning Break**, **Lunch Beak**, or **Afternoon Break** to open the timecard task.
4. Select **Scan now** for the break you want to record.
5. Select **Scan per group** or **Scan per individual**.
   - **Scan per group**: assign members to a group for the current time card.
   - **Scan per individual**: scan in employees without creating groups for the current time card.
6. Scan the QR codes on each employee's badge.
   - The employee names will show up under **Selected Members** as they are successfully scanned.
7. Select **Clock In Members**. A  **confirmation screen** appears, showing that the break has started.
8. When the employee breaks are over, select **Scan now** for the break you want to end.
9. Select the **Scan** button <img src="/images/IMG_9638.jpg" alt="Crew icon mobile" noZoom style={{ width: "32px", height: "auto", display: "inline-block", verticalAlign: "middle", margin: 0 }} /> at the bottom right of the page.

10. Select **Scan per group** or **Scan per individual**.
11. Scan the QR codes on each employee's badge.

- - The employee names will show up under **Selected Members** as they are successfully scanned.

12. Select **Clock In Members**. A **confirmation screen** appears, showing that the break has ended.

You can **skip any breaks** that do not apply to the workday.

---

### Clock employees out

Select the **Timecard** page <img src="/images/IMG_9638.jpg" alt="Crew icon mobile" noZoom style={{ width: "32px", height: "auto", display: "inline-block", verticalAlign: "middle", margin: 0 }} /> from the bottom menu. 2. Find and select the timecard you want to clock employees out for. 3. Select **Clock Out Members** to open the timecard task. 4. Select **Scan now**. 5. Select **Scan per group** or **Scan per individual**.

- **Scan per group**: assign members to a group for the current time card.
- **Scan per individual**: scan in employees without creating groups for the current time card.

6. Scan the QR codes on each employee's badge.
   - The employee names will show up under **Selected Members** as they are successfully scanned.
7. Select **Clock Out Members**.
8. Confirm your changes by selecting **Confirm & Submit**.

A  **confirmation screen** appears, showing that the break has started. 8. When the employee breaks are over, select **Scan now** for the break you want to end. 9. Select the **Scan** button <img src="/images/IMG_9638.jpg" alt="Crew icon mobile" noZoom style={{ width: "32px", height: "auto", display: "inline-block", verticalAlign: "middle", margin: 0 }} /> at the bottom right of the page. 10. Select **Scan per group** or **Scan per individual**. 11. Scan the QR codes on each employee's badge.

- The employee names will show up under **Selected Members** as they are successfully scanned.

12. Select **Clock In Members**. A **confirmation screen** appears, showing the number of employees successfully clocked out and the timecard number.

Once all employees are clocked out, the timecard status will change to **Submitted**.
