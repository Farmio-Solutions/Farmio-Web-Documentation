## Quickstart Guide

### Find a timecard

Any time cards scheduled for that day will show on the **Home Page**. 

![IMG 0278](/images/IMG_0278.PNG "IMG 0278")

**You can also find time cards for the current pay period:**

1. Select the **Timecard** page <img src="/images/IMG_9865-4.PNG" alt="Crew icon mobile" noZoom style={{ width: "32px", height: "auto", display: "inline-block", verticalAlign: "middle", margin: 0 }} /> from the bottom menu.

![IMG 9865](/images/IMG_9865-2.PNG "IMG 9865")

2. You can search for a specific time card by selecting a date and/or crew. 

![IMG 0280](/images/IMG_0280.PNG "IMG 0280")

<Info>
  The mobile app only shows time cards for the current pay period. You can find a timecard for any pay period in the [web version](#va4).
</Info>

### Export an employee badge

1. Select the **Crew** page <img src="/images/IMG_9638.jpg" alt="Crew icon mobile" noZoom style={{ width: "32px", height: "auto", display: "inline-block", verticalAlign: "middle", margin: 0 }} /> from the bottom menu.

![IMG 9637](/images/IMG_9637-1.jpg "IMG 9637")

3. Enter the employee's first name, last name, or Employee ID.
4. Select the employee you want to update.

![IMG 9634](/images/IMG_9634.PNG "IMG 9634")

5. Select the **export** button <img src="/images/image-7.png" alt="Crew icon mobile" noZoom style={{ width: "32px", height: "auto", display: "inline-block", verticalAlign: "middle", margin: 0 }} /> in the top right of the page.

### Clock employees in

1. Select the **Timecard** page <img src="/images/IMG_9865-4.PNG" alt="Crew icon mobile" noZoom style={{ width: "32px", height: "auto", display: "inline-block", verticalAlign: "middle", margin: 0 }} /> from the bottom menu.

![IMG 9865](/images/IMG_9865-2.PNG "IMG 9865")

2. Find and select the timecard you want to clock employees in for.

![IMG 9813](/images/IMG_9813.PNG "IMG 9813")

3. Under **Timecard tasks**, select **Scan now** in the **Clock In Members** section.

![IMG 9814](/images/IMG_9814.PNG "IMG 9814")

4. Select **Scan per group** or **Scan per individual**.

- **Scan per group**: assign members to a group for the current time card.
- **Scan per individual**: scan in employees without creating groups for the current time card.

![IMG 9815](/images/IMG_9815.PNG "IMG 9815")

5. Scan the QR codes on each employee's badge.

- The employee names will show up under **Selected Members** as they are successfully scanned.

6. Select **Clock In Members**. 

![IMG 9818](/images/IMG_9818.PNG "IMG 9818")

A **confirmation screen** appears, showing the number of employees successfully clocked in and the timecard number.

![IMG 9841](/images/IMG_9841.png "IMG 9841")

### Record employee breaks

1. Select the **Timecard** page <img src="/images/IMG_9865-4.PNG" alt="Crew icon mobile" noZoom style={{ width: "32px", height: "auto", display: "inline-block", verticalAlign: "middle", margin: 0 }} /> from the bottom menu.

![IMG 9865](/images/IMG_9865-2.PNG "IMG 9865")

2. Find and select the timecard you want to record a break for.

![IMG 9813](/images/IMG_9813.PNG "IMG 9813")

3. Select **Morning Break**, **Lunch Beak**, or **Afternoon Break** to open the timecard task.
4. Select **Scan now** for the break you want to record.

![IMG 9849](/images/IMG_9849.PNG "IMG 9849")

5. Select **Scan per group** or **Scan per individual**.

- **Scan per group**: assign members to a group for the current time card.
- **Scan per individual**: scan in employees without creating groups for the current time card.

![IMG 9815](/images/IMG_9815.PNG "IMG 9815")

6. Scan the QR codes on each employee's badge.

- The employee names will show up under **Selected Members** as they are successfully scanned.

![IMG 9818](/images/IMG_9818.PNG "IMG 9818")

7. Select **Clock In Members**. 
   1. A  **confirmation screen** appears, showing that the break has started.

![IMG 9850](/images/IMG_9850.PNG "IMG 9850")

8. When the employee breaks are over, select **Scan now** for the break you want to end.

![IMG 9849](/images/IMG_9849.PNG "IMG 9849")

9. Select the **Scan** button <img src="/images/IMG_9851.PNG" alt="scan icon mobile" noZoom style={{ width: "32px", height: "auto", display: "inline-block", verticalAlign: "middle", margin: 0 }} /> at the bottom right of the page.

![IMG 9852](/images/IMG_9852.png "IMG 9852")

10. Select **Scan per group** or **Scan per individual**.
11. Scan the QR codes on each employee's badge.

- The employee names will show up under **Selected Members** as they are successfully scanned.
  ![IMG 9818](/images/IMG_9818.PNG "IMG 9818")

12. Select **Clock In Members**. 
    1. A **confirmation screen** appears, showing that the break has ended.
    2. You can **skip any breaks** that do not apply to the workday.
       ![IMG 9853](/images/IMG_9853.PNG "IMG 9853")

### Clock employees out

1. Select the **Timecard** page <img src="/images/IMG_9865-4.PNG" alt="Crew icon mobile" noZoom style={{ width: "32px", height: "auto", display: "inline-block", verticalAlign: "middle", margin: 0 }} /> from the bottom menu.

![IMG 9866](/images/IMG_9866.png "IMG 9866")

4. Select **Scan now**.
5. Select **Scan per group** or **Scan per individual**.

- **Scan per group**: assign members to a group for the current time card.

![IMG 9861](/images/IMG_9861.jpg "IMG 9861")
