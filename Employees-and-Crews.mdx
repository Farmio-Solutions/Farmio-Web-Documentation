    ## 1. Create a new employee

    1. Navigate to the Employees page.
    2. Click "+ Add Employee".
    3. To add a single employee, choose "Add employee" from the dropdown options. <img src="/images/add-single-employee.png" alt="Add Single Employee" title="Add Single Employee" />

    <Info>
      If you want to add multiple employees, go to [2. Create Employees from Bulk Form](#2-create-employees-from-bulk-form).
    </Info>
